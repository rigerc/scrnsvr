## Rendering requirements
Intermediate passes must preserve the original layer input without sampling and rendering into the same target; three reusable full-resolution color scratch targets maximum for multipass (old nonmultipass paths retain one/two). Bloom is brightness extraction -> horizontal Gaussian -> vertical Gaussian -> final combine, using threshold/radius/strength/intensity. Clamp all sample taps to edge texel centers; bounded static GLSL loops support ES1.00. No depth/mipmaps. Map metadata types to actual uniforms: color->RGB vector, select->option index, bool/int->integer uploads. Keep zero-intensity direct bypass.

Datamosh / Trails is actual per-instance persistent frame feedback, not simulated noise. Two history surfaces per enabled temporal instance at drawing-buffer resolution are an allowed additional cost; allocate lazily, bound by existing eight-layer limit, release on bypass/removal/zero intensity and teardown. Initialize safely from input/no-history; never sample a texture being written. Freeze history and time on Pause/zero-delta redraws (including repeated forced redraw); keep latest displayed frame stable rather than repeatedly accumulating it. Reset histories on resize, stack structural/parameter edits, enable transitions and base remount to prevent stale dimensions/content; do not reset effect time for edits. When running, history updates once per frame only and suspension must not accumulate a giant delta. New temporal sources use proper uDelta (frame-rate-adjusted decay where feasible) and mode select 0=Trails/1=Datamosh. Datamosh block displacement is local, bounded and slow; no abrupt full-screen flashes.

Existing OGL WebGL1 texture bug workaround (prime unused wrapR state) must also apply to any new targets. Preserve program/resource cache cleanup and warning-clear/re-notification on recovery. Unknown/compile failures skip layer. History allocation failures must safely bypass affected temporal work or stack, keep config and render base/healthy output with diagnostic. No new context/no dependency installation.
