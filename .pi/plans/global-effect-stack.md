# Approved implementation: Global Effect Stack with VHS Distortion

User decisions: built-in VHS first (no custom-effect editor); ordered stack; shader visual only (clock/fade unchanged); main/fullscreen preview and saver effects but clean thumbnails; effect motion independent of base visual speed, frozen by preview Pause.

## Shared contract
`src/shared/effects.ts` defines MAX_EFFECT_LAYERS=8, EffectManifest (id/title/description/uniforms), EffectDefinition extends manifest with source, EffectLayer (id/effectId/enabled/values), EffectsConfig (enabled/layers), EffectRuntimeOptions (effects?: mutable config, onEffectStatus?: callback), EffectStatus (layerId?: string/message). `effectManifests` contains vhs-distortion metadata. `resolveEffectValues` defaults/clamps known metadata values. `normalizeEffects` repairs malformed effect sections, generates deterministic unique instance IDs, caps eight layers, preserves unknown effect IDs and safe values. Config.effects defaults enabled/empty.

## Renderer
Extend mountShader with optional sixth `EffectRuntimeOptions` argument, no API breaking existing callers. Build `src/renderer/effects/index.ts` effectRegistry from shared metadata + VHS source. Add original GLSL ES WebGL1/2-compatible single-pass VHS shader: texture input uInput, normalized vUv, physical uResolution, independent elapsed uTime; controls intensity .5/grain .2/scanlines .25/colorBleed .2/tracking .15 (0..1 step .01). Clamped resolution-aware texture offsets; subtle scanlines/grain/channel split/jitter/tracking band, no heavy vignette/curvature/fullscreen flash, intensity0 bypass.

Add controller to runtime: base direct rendering and zero targets when stack empty/global bypass/no effective layers; otherwise base->offscreen->layers ordered with max two reusable color RGBA8 linear clamp-to-edge no depth/stencil/mipmaps ping-pong targets, last layer to canvas. Reconcile by instance ID on edits/reorder, retain programs and time, detect effect changes while paused and redraw without time. Time independent of visual speed; base remount/shuffle retains existing semantics (new timeline). Resize drawing-buffer-sized targets only on actual dimensions changes. Validate real compile/link and framebuffer status; skip individual broken/unavailable layers preserving config and warn once per layer; framebuffer failures bypass stack without blanking scene. Clean programs/shaders/targets/cache on removal/teardown. Share existing OGL renderer context/state. GPU harness WebGL1/2 tests orientation, two synthetic noncommutative layers, repeat/toggle/reorder, zero/bypass direct identity, VHS moving/paused/speed0, odd/nonpower2 resize, remount/switch/failures/clean GL errors. Unit tests for lifecycle and runtime semantics.
