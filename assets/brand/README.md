# scrnsvr — Focus logo kit

## Approved direction
**Focus** — an organic wave and focal dot, tuned for a screensaver desktop app.

## Core idea
The mark suggests ambient motion, drift, and light without literally drawing a screen or monitor.
It is intended to feel calm, modern, and slightly technical.

## Usage
### Preferred use
- Use the **app icon master** for desktop/app contexts.
- Use the **small-size cut** at 16–32 px.
- Use the **standalone symbol** where the rounded-square tile is not needed.
- Use the **horizontal lockup** for headers, README pages, and UI marketing placements.
- Use the **stacked lockup** where vertical space is available.

### Minimum sizes
- App icon: **16 px** minimum using the small-size cut.
- Symbol only: **20 px** minimum height.
- Horizontal lockup: **120 px** minimum width.
- Stacked lockup: **96 px** minimum width.

### Clear space
Use clear space equal to approximately the **dot diameter** on all sides.
Do not place text or other graphics inside this space.

### Backgrounds
- Full-colour versions work best on **white**, very light neutral backgrounds, or the built-in dark tile.
- Use **white reversed** variants on dark backgrounds.
- Use **black** or **mono** variants when gradients are unsuitable.

### Do not
- Recolour the gradient arbitrarily.
- Stretch or compress the mark.
- Separate the dot too far from the wave.
- Put the full-colour standalone symbol on a background so dark that the dark dot disappears.
- Use the large-size icon master below 32 px.

## Notes / limitations
- The lockup wordmark is based on **DejaVu Sans Bold**, converted to paths for portability. It is a practical production placeholder, not a separately custom-drawn logotype.
- The wave remains a **stroke-based vector path** in this kit. If you want, a later pass can convert it into a fully expanded filled-outline master.
- This kit does **not** include trademark clearance.
